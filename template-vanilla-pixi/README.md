# template-vanilla-pixi

Vite + TypeScript + [PixiJS](https://pixijs.com/) starter — no framework.

## Getting Started

```bash
yarn install
yarn dev
```

## Scripts

| Script         | Description                          |
| -------------- | ------------------------------------ |
| `yarn dev`     | Start the Vite dev server            |
| `yarn build`   | Type-check and bundle for production |
| `yarn preview` | Preview the production build         |
| `yarn lint`    | Lint with ESLint                     |

## Stack

- **Vite** — fast dev server and bundler
- **TypeScript** — strict type checking
- **PixiJS v8** — 2D rendering engine
